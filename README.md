# 個人履歷網站 (Personal Portfolio)

這是一個專為「社會新鮮人」與「初階開發者」設計的現代化個人作品集網站。採用 Vue 3 與 Vite 建置，具備毛玻璃 (Glassmorphism) 視覺風格與完全的響應式設計。

## 功能特色

- **首頁視覺區 (Hero Area)**：具有漸層文字、動態背景球體與專屬的程式碼風格自我介紹。
- **關於我 (About)**：個人簡介與自訂進度條技術棧展示。
- **作品集 (Projects)**：網格排版 (Grid) 搭配懸停 (Hover) 特效的專案展示區。
- **經歷時間軸 (Experience)**：垂直時間軸呈現學歷、社團與實習經歷。
- **聯絡我 (Contact)**：簡潔的聯絡資訊與毛玻璃風格表單。

## 使用技術

- [Vue 3](https://vuejs.org/) (使用 `<script setup>` 語法)
- [Vite](https://vitejs.dev/) (極速的前端建置工具)
- **Vanilla CSS** (使用 CSS 變數建立設計系統，無依賴外部 UI 框架)

## 如何在本地端執行

1. **安裝依賴套件**
   ```bash
   npm install
   ```

2. **啟動開發伺服器**
   ```bash
   npm run dev
   ```

3. **打包編譯 (Production)**
   ```bash
   npm run build
   ```
